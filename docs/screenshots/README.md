# Screenshots

Drop screenshots here so they render in the main project [`README.md`](../../README.md).

Expected files (referenced by the README):

| Filename | What to capture |
|----------|-----------------|
| `home.png` | The home page hero — logo, "PREMIUM SPORTS BETTING" headline, stats bar. |
| `testimonials.png` | The `/testimonials` page showing Discord-sourced testimonial cards. |
| `vip.png` | The "UNLOCK VIP ACCESS" section with the ambient gold animation. |

## How to capture

1. Run the app: `npm run dev` and open http://localhost:3000.
2. Use your OS screenshot tool (Win: `Win+Shift+S`, Mac: `Cmd+Shift+4`) or your browser's
   built-in full-page capture (DevTools → ⋯ → *Capture screenshot*).
3. Save as PNG with the exact filenames above into this folder.
4. Aim for ~1280px wide for crisp rendering on GitHub.

> Tip: a short screen recording converted to GIF makes the animations pop on the README,
> but keep file size reasonable (< ~5 MB).
